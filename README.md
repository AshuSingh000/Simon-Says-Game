# Simon-Says-Game

A modern, interactive memory game inspired by the classic **Simon Says** challenge, built using **HTML, CSS, and JavaScript**. Players must accurately reproduce an increasingly complex sequence of colors and sounds generated by the game. Each successful round adds a new step to the sequence, testing memory, concentration, and reaction speed.

## Key Features

* Dynamic random sequence generation
* Progressive difficulty with unlimited levels
* Smooth animations and visual feedback
* Interactive sound effects for each button
* Real-time score and level tracking
* Responsive design for desktop and mobile devices
* Clean, modular, and maintainable JavaScript code

## Technologies Used

* HTML
* CSS
* JavaScript 
* DOM Manipulation
* Event Handling

This project demonstrates core front-end development concepts, including DOM manipulation, event-driven programming, game state management, animations, timing functions, and responsive UI design, making it an excellent beginner-to-intermediate JavaScript project.
